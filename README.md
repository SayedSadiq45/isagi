# Isagi Awakening

An immersive Blue Lock-inspired landing experience built around Isagi Yoichi's evolution from field vision to direct ego.

## Live Experience

**[Open Isagi Awakening](https://isagi-xi.vercel.app/isagi.html)**

Move your pointer across the scene to reveal Isagi's awakened state. The interactive canvas blends two visual layers into a living spotlight that follows your movement.

## Highlights

- Full-screen cinematic hero composition
- Interactive image reveal with a smooth cursor trail
- Responsive layout for desktop and mobile screens
- Blue Lock-inspired typography, electric blue accents, and animated glow effects
- Direct links to the creator's GitHub and LinkedIn profiles
- Lightweight static HTML with no build step or framework required

## Run Locally

Clone the repository and open `index.html` in a browser. For the most reliable local experience, serve the folder with any static web server:

```bash
npx serve .
```

Then open the local URL shown in your terminal. The entry page redirects to `isagi.html`.
